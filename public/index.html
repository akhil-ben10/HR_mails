Connect your Gmail

This app uses Google's official sign-in to send from your account. A one-time OAuth setup is required.

  1. Open Google Cloud Console and create a project.
  2. Enable the Gmail API.
  3. In Google Auth Platform, configure Branding and Audience. For personal use choose External / Testing and add your Gmail as a test user.
  4. Add the scope https://www.googleapis.com/auth/gmail.send under Data Access.
  5. Create a Web application OAuth client. Add this exact Authorized JavaScript origin:
  6. Paste its Client ID below. No client secret or Gmail password is needed.

Google may require verification for wider distribution. Personal testing must use an added test user. Keep this tab open while sending; this app does not run in the background.
